# Yux 与 Kotlin / Java 混合项目示例

> 前置：`02-Yux-编译器架构.md` §11（构建管线）。
> 场景：同一构建单元中混用 `.yux`、`.kt`、`.java` 源码，三方自由互调。这是企业迁移与复用现有代码的常见形态。

## 1. 场景与动机

- 团队已有 Java/Kotlin 业务代码，新功能用 Yux 快速开发。
- Yux 负责高生产力 DSL（事件、命令、配置、序列化）；Kotlin 负责既有框架适配；Java 保留历史实现。
- 三方最终打进同一个 jar，共享同一个 ClassLoader 与类型系统。

## 2. 目录布局

```
MyServer/
├── build.yml
├── src/                  # Yux 源码（默认）
│   ├── main.yux
│   └── Economy.yux
├── kotlin/               # Kotlin 源码
│   └── com/example/Bridge.kt
├── java/                 # Java 源码
│   └── com/example/LegacyLib.java
├── resources/
└── tests/                # 测试（可含 Yux/Java 测试）
```

## 3. build.yml（混合配置）

```yaml
name: MyServer
version: 1.0.0

language:
  yux: 1.0

target:
  jvm: 21

source:
  main: src              # Yux 源码根
  kotlin: kotlin         # 可选
  java: java             # 可选

dependencies:
  minecraft:
    paper: 1.21
  maven:
    - group: com.example
      artifact: shared-api
      version: 2.0

plugins:
  minecraft: true
  serialization: true
  injection: true
```

## 4. 编译顺序（关键规则）

```
1. 统一符号收集：Java + Kotlin + Yux 的公开类型名全部进入符号表
2. 编译 Java 源码（javac，产出 .class）
3. 编译 Kotlin 源码（kotlinc，产出 .class）
4. 编译 Yux 源码（yuxc，产出 .class，可引用前两步产物与自身）
5. Gradle 打包：所有 .class + resources → jar
```

- S-05.1 **依赖方向**：Java → Yux、Kotlin → Yux 属于「跨语言引用」，编译顺序由 build-tool 根据符号解析自动排列；Yux 反向引用 Java/Kotlin 总是允许。
- S-05.2 Yux 引用 Kotlin/Java 类型无需额外配置（同一构建单元），只需 `import`。
- S-05.3 循环依赖（Yux↔Kotlin 互相引用类型）在**构建期**允许，但禁止「值初始化时的构造循环」（与 Java 相同的循环引用限制）。

## 5. 三方互操作

### 5.1 Yux 调用 Java（§01-8.5）

```yux
import org.bukkit.Bukkit
import com.example.LegacyLib

fun broadcast(title:String, body:String) {
    LegacyLib.sendTitleAll(Bukkit.getServer(), title, body)
}
```

```java
// com/example/LegacyLib.java（既有代码，不改动）
public final class LegacyLib {
    public static void sendTitleAll(Server s, String t, String b) { /* ... */ }
}
```

### 5.2 Yux 调用 Kotlin

```kotlin
// com/example/Bridge.kt
object Economy {
    fun deposit(player: String, amount: Double): Double = /* ... */
}
```

```yux
import com.example.Economy

fun pay(playerName:String, amount:Double) {
    balance = Economy.deposit(playerName, amount)
    print "$playerName 余额: $balance"
}
```

### 5.3 Kotlin 调用 Yux

Yux 顶级对象编译为普通 JVM 类（§01-5），Kotlin 按普通 JVM 类型使用：

```kotlin
// com/example/KotlinSide.kt
import yux.generated.MyServerKt       // Yux 顶层函数所在文件类
import com.example.HomeData           // Yux data 类

fun handle() {
    MyServerKt.pay("Steve", 50.0)
    val data = HomeData("Steve", emptyMap())
}
```

> 文件类命名规则与 Kotlin 相同：`Foo.yux` 顶层成员 → `FooKt`（或按 package 生成的 `package-info` 约定）。该命名由 build-tool 记录并在 Kotlin 侧可 IDE 补全。

### 5.4 Java 调用 Yux

```java
// com/example/JavaSide.java
import com.example.HomeData;
import yux.generated.HomeCommand;

public class JavaSide {
    public void run() {
        HomeData d = new HomeData("Steve", Map.of());
        System.out.println(d);            // HomeData(player=Steve, homes={})
        HomeCommand.INSTANCE.execute(...);
    }
}
```

### 5.5 互操作注解

- Yux 侧可用 `@JvmField`/`@JvmStatic`（Java 注解）调整暴露形式，与 Kotlin 行为一致：

```yux
@JvmStatic
fun createDefault():HomeData = HomeData("default", Map String LocationData())
```

## 6. 生成的 Gradle 脚本（build-tool 产物）

```kotlin
// build.gradle.kts（生成）
plugins {
    java
    kotlin("jvm") version "2.0.21"
    application
}

java {
    toolchain { languageVersion.set(JavaLanguageVersion.of(21)) }
}

dependencies {
    implementation("org.ow2.asm:asm:9.7")
    implementation("io.papermc.paper:paper-api:1.21-R0.1-SNAPSHOT")
    implementation("com.example:shared-api:2.0")
}

sourceSets {
    main {
        java {
            srcDir("java")            // Java
            srcDir("kotlin")          // Kotlin 源码（Kotlin 插件读取）
            srcDir("build/yux-classes") // Yux 编译产物
        }
        resources.srcDir("resources")
    }
}

tasks.register<Exec>("compileYux") {
    // 顺序：javac → kotlinc → yuxc（见 §4），产物输出到 build/yux-classes
}

tasks.compileJava.dependsOn("compileYux")
tasks.processResources.dependsOn("compileYux")
```

- `yuxc build` 负责编排：解析 build.yml → 生成脚本 → 以正确顺序调用编译链 → Gradle 打包。

## 7. 依赖注入与 service 混用

- Yux `service` 由 `yux.di` 容器托管；Kotlin/Java 侧通过容器获取：

```yux
service EconomyService {
    balance:Int = 0
    fun add(amount:Int) { balance += amount }
}
```

```kotlin
val svc = YuxDi.inject<EconomyService>()   // Kotlin 使用 Yux service
```

## 8. 常见问题与约束

| 问题 | 处理 |
|---|---|
| Kotlin 调用 Yux 顶层函数找不到类 | 按文件类命名规则引用；build-tool 输出映射表 `yux-symbols.json` 供 IDE/编译 |
| Yux 引用 Kotlin `object`/`companion` | 走 JVM 静态/实例成员，正常调用 |
| 三方同名类型冲突 | 报错并要求显式 `import` 全限定名 |
| Kotlin 的 `internal` 对 Yux | Yux 视为普通 JVM 可见性，`internal` 项不可见（与 Java 相同） |
| Yux 泛型 ↔ Kotlin 泛型 | 擦除后按 JVM 类型互操作，签名保留 |

## 9. 小型完整示例（三方协作：玩家余额）

```
MyServer/
├── build.yml
├── src/Economy.yux            # Yux：data + service + 命令
├── kotlin/Currency.kt         # Kotlin：货币格式化 + 既有对象
└── java/Logger.java           # Java：遗留日志
```

**Economy.yux**

```yux
import com.example.Currency
import com.example.Logger

data Account {
    player:String
    balance:Double
}

service EconomyService {
    accounts:Map String Account = Map String Account()
    logger:Logger = Logger.getInstance()

    fun deposit(player:String, amount:Double):Double {
        acc = accounts.get(player) ?: Account(player, 0.0)
        acc.balance += amount
        accounts[player] = acc
        logger.log("${player} 存入 ${Currency.format(amount)}")
        return acc.balance
    }
}

command "/balance" {
    permission = "myserver.balance"
    execute(sender, args) {
        player = sender as Player
        acc = inject(EconomyService).accounts.get(player.name) ?: Account(player.name, 0.0)
        player.send "余额: ${Currency.format(acc.balance)}"
        return true
    }
}
```

**Currency.kt**

```kotlin
package com.example

object Currency {
    fun format(amount: Double): String =
        "$${String.format("%,.2f", amount)}"
}
```

**Logger.java**

```java
package com.example;

public final class Logger {
    private static final Logger INSTANCE = new Logger();
    public static Logger getInstance() { return INSTANCE; }
    public void log(String msg) { System.out.println("[MyServer] " + msg); }
}
```

**构建与运行**

```
yuxc build          # 生成 Gradle 脚本 → javac/kotlinc/yuxc → jar
yuxc run
```

# 附录：互操作速查表

| 方向 | 形式 |
|---|---|
| Yux → Java | `import` + 类型名/静态成员；JavaBean 属性语法 |
| Yux → Kotlin | `import` + 类名/object 成员 |
| Kotlin → Yux | 文件类名 + 顶层成员；data 类普通构造 |
| Java → Yux | 普通 JVM 类型；文件类静态成员 |
| 注解 | 三方注解互相可见（`@JvmField`/`@EventHandler`/`@Serializable`） |
