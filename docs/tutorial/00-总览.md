# Yux 入门到精通 · 总览

> **语言圣经**：从零基础到精通 Yux 语言与生态的完整教程。
> 主线读者：**零基础新手** —— 不需要任何编程经验。
> 版本锁定：**v0.1.0-m15**（M14 异步协程 + M15 SSA 优化器后的稳定语言面）。

## 0. 这是什么样的教程

本教程不是规范复读机，而是**活文档**：

- 每一章的讲解都对应一组**真实可运行**的示例（`samples/tutorial/`）；
- 所有示例都由编译器逐条验证，输出快照（`.stdout`/`.err`）纳入 CI 自动比对；
- 文档里贴的代码不会过期 —— 语言变了，测试会先红。

```text
docs/tutorial/            ← 你正在读的教程正文
samples/tutorial/<篇>/    ← 与正文一一对应的 golden 示例（编译器验证）
```

### 示例怎么跑

安装工具链后（见 §1），示例即跑即得：

```bash
# 正例：应输出与 .stdout 快照一致的内容
yuxc run samples/tutorial/01-intro/02-hello.yux

# 反例：应编译失败，stderr 与 .err 快照一致
yuxc run samples/tutorial/01-intro/17-type-mismatch.yux
```

示例文件名前的 `NN-` 数字对应该章在教程正文中的序号。

## 1. 一分钟安装

Yux 工具链是单文件脚本 `setupyux.sh`，一条命令完成：

```bash
# 安装最新版（main）
curl -fsSL https://raw.githubusercontent.com/FallingSkyQwQ/yux/main/setupyux.sh | bash

# 锁定教程对应版本
curl -fsSL https://raw.githubusercontent.com/FallingSkyQwQ/yux/main/setupyux.sh | bash -s -- --ref v0.1.0-m15
```

脚本行为：

- 支持 **Linux / macOS / WSL**；要求 **JDK 21+**（缺失时给出安装指引，不自动装）；
- 优先下载 GitHub Releases 的免编译产物；没有则 clone 源码用 Gradle 编译；
- 安装到 `~/.yux/bin/yuxc`，并把 `~/.yux/bin` 幂等地写入 PATH；
- 幂等：重复运行不会重复安装或重复改写 PATH。

安装完成后新开终端，或先手动 `export PATH="$HOME/.yux/bin:$PATH"`，然后：

```bash
yuxc --help          # 查看全部命令
yuxc run hello.yux   # 编译并运行
yuxc check hello.yux # 只做语义检查
yuxc ast hello.yux   # 查看语法树
yuxc ir  hello.yux   # 查看中间表示
```

## 2. Yux 是什么

一句话：**Yux 是为 JVM 生态设计的极简静态类型语言**，以 Minecraft 插件为第一场景，
但本身是完整的通用语言。它的性格：

| 性格 | 体现 |
| --- | --- |
| 极简 | 无 `class`/`val`/`return` 噪音；类声明就是 `Name { ... }` |
| 静态类型 | 编译期类型检查，但局部变量类型大多可推断 |
| 空安全 | 可空类型 `T?` + 编译提醒 + 运行保护（不强制） |
| 并发内置 | `async`/`await`/`parallel` 是一等语法 |
| JVM 互操作 | `import java.*` 直接调 Java 类库 |
| 可扩展 | 编译器插件 API 可加新语法（Minecraft 扩展即插件） |

与主流语言对照（详见 04-生态门户）：

- 语法观感像 **Kotlin + Python**（省略样板、`$` 插值、`it` 隐式参数）；
- 类型系统像 **Kotlin**（可空、泛型无尖括号 `List Int`、密封类）；
- 运行在 **JVM** 上，与 Java/Kotlin 库无缝互操作。

## 4. 术语表（速记版）

| 术语 | 含义 |
| --- | --- |
| `yuxc` | Yux 编译器命令行（lex/ast/check/ir/run/build/test） |
| 顶级对象 | 文件中顶层声明：类 / `data` / `service` / 函数 / 顶层属性 |
| 属性 | 类字段 + 自动生成 getter/setter（可自定义） |
| 扩展函数 | 给已有类型追加成员方法的语法（`fun Receiver.name()`） |
| data 类 | 自动生成构造器 / `equals` / `hashCode` / `toString` / 序列化的类 |
| service | 依赖注入载体（构造器自动注入） |
| 密封类 | `sealed` 修饰，子类固定、`when` 可穷尽检查 |
| 智能转型 | 判空 / `is` 检查后，编译器自动收窄变量类型 |
| golden 示例 | 有输出快照、由 CI 逐字节比对的示例 |
