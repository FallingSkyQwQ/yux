# Yux 入门（第一章到第十二章）

> 主线：零基础。每一章先讲概念，再给一个**经过编译器验证**的示例（`samples/tutorial/01-intro/`），
> 章末有速查与规范指引。建议边读边在终端跑一遍 `yuxc run <示例>`。

---

## 第 1 章 你好，Yux

写第一个程序只需要一个函数：

```yux
// samples/tutorial/01-intro/02-hello.yux
fun main() {
    print "Hello Yux"
}
```

```text
$ yuxc run samples/tutorial/01-intro/02-hello.yux
Hello Yux
```

要点：

- `fun main()` 是程序入口。程序从这里开始执行。
- `print "Hello Yux"` 把字符串输出到标准输出（**不换行**；换行用 `println`）。
- 函数体用 `{ }` 包裹，语句换行分隔，分号可选。
- `//` 是单行注释；`/* ... */` 是多行注释（规范 §2.2）。

> 反例示例（`.err`）：文件名 `NN-*.yux` 带 `.err` 快照的是**故意写错**的代码，
> 演示编译器如何报错。正例带 `.stdout` 快照。

## 第 2 章 变量与类型

变量用 `名字 = 值` 声明（类型自动推断），也可以显式标注类型：

```yux
// samples/tutorial/01-intro/03-variables.yux
fun main() {
    count = 18
    score:Double = 3.14
    name:String = "Steve"
    active:Boolean = true
    print count
    print score
    print name
    print active
}
```

```text
18
3.14
Steve
true
```

Yux 的**基本类型**（示例 `10-types.yux`）：

| 类型 | 字面量示例 | 说明 |
| --- | --- | --- |
| `Int` | `42` | 整数 |
| `Double` | `3.14` | 浮点数 |
| `Boolean` | `true` / `false` | 布尔 |
| `Char` | `'X'` | 单字符 |
| `String` | `"yux"` | 字符串 |
| `Any` | — | 任意类型的父类型 |
| `T?` | `String?` | 可空类型（第 8 章） |

要点：

- 推断规则（规范 §4.5）：`count = 18` 推断为 `Int`；显式 `:Double` 可强制类型。
- 变量默认**可变**，用 `=` 重新赋值；赋值类型必须兼容（不兼容见反例 `17-type-mismatch.yux`，
  报 E0004 类型不匹配）。
- 局部变量**必须先赋值再使用**，否则编译报错（E0007，规范 S-6.1.2）。

> 反例：`samples/tutorial/01-intro/17-type-mismatch.yux` —— `x:Int = "hello"`，
> 期望 `Int` 实际 `String`，编译期拒绝，不会等到运行期。

## 第 3 章 字符串与插值

字符串用双引号；`$` 做**插值**：

```yux
// samples/tutorial/01-intro/04-strings.yux
fun main() {
    name = "Alex"
    level = 3
    print "hi $name"
    print "level=${level + 1}"
    print "\$escaped"
}
```

```text
hi Alex
level=4
$escaped
```

要点（规范 §7.6）：

- `$name`：变量插值，替换为变量值。
- `${表达式}`：任意表达式插值，如 `${level + 1}`。
- `\$`：转义美元符，输出字面 `$`。
- 字符串拼接用 `+`：`"val=" + 42` 得到 `"val=42"`。

## 第 4 章 条件分支 if / else

```yux
// samples/tutorial/01-intro/05-conditionals.yux
fun main() {
    health = 8
    if health <= 0 {
        print "dead"
    } else if health < 10 {
        print "low"
    } else {
        print "fine"
    }
    msg = if health > 0 then "alive" else "dead"
    print msg
}
```

```text
low
alive
```

要点（规范 §6.2）：

- `if 条件 { } else if { } else { }`：条件必须是 `Boolean`（否则 E0003）。
- **if 表达式**：`msg = if 条件 then A else B` —— 条件为真取 `A`，否则取 `B`。
  这是 Yux 常见的“表达式作值”风格，贯穿全书。

---

## 第 5 章 when 多路分支

多个分支用 `when`，比 `if/else if` 更清晰：

```yux
// samples/tutorial/01-intro/11-when.yux
fun main() {
    level = 2
    when level {
        1 -> print "beginner"
        2 -> print "intermediate"
        else -> print "unknown"
    }
    println ""
    msg = when level {
        1 -> "low"
        2 -> "mid"
        else -> "high"
    }
    println msg
}
```

```text
intermediate
mid
```

要点（规范 §6.3）：

- `when 值 { 分支 -> 体 }`，`else` 兜底。
- when 也可以作**表达式**（产生值）：`msg = when level { ... }`。
- 表达式形态必须**穷尽**：非密封类型的 when 表达式缺 `else` 会报 E0034
  （反例 `16-when-no-else.yux`）。密封类型的穷尽规则见 02-进阶 第 12 章。

## 第 6 章 循环 for / while

```yux
// samples/tutorial/01-intro/06-loops.yux
fun main() {
    for i in 0..3 {
        print i
    }
    x = 0
    while x < 3 {
        x = x + 1
    }
    print x
}
```

```text
0123
3
```

要点（规范 §6.4）：

- `for 变量 in 范围/集合 { }`：`0..3` 是闭区间 `[0,3]`；也可以迭代 `List`、字符串、数组。
- `while 条件 { }`：条件为真时反复执行。
- 循环体内可用 `break` 跳出、`continue` 进入下一轮（规范 §6.5）。
- 复合赋值 `x += 1` 等价于 `x = x + 1`（详见 02-进阶 第 19 章）。

## 第 7 章 函数

函数把代码组织成可复用的单元：

```yux
// samples/tutorial/01-intro/07-functions.yux
fun add(a:Int, b:Int):Int {
    return a + b
}
fun greet(name:String, title:String = "Mr.") = "Hi $title $name"
fun main() {
    print add(1, 2)
    print greet("Steve")
    print greet("Alex", "Dr.")
}
```

```text
3
Hi Mr. Steve
Hi Dr. Alex
```

要点（规范 §5.5）：

- `fun 名字(参数:类型):返回类型 { }`；`return` 返回值。
- **表达式体**：`fun greet(...) = 表达式` —— 函数体直接是一个表达式，省去 `return`。
- **参数默认值**：`title:String = "Mr."` —— 调用时省略该实参则用默认值。
  实参齐全时调用 `greet("Alex", "Dr.")` 与缺省调用 `greet("Steve")` 并存。
- 默认值可以引用**更早的形参**（如 `fun scale(x:Int, factor:Int = x * 2)`），
  见 02-进阶 第 1 章。
- 默认值表达式必须可赋值给形参类型（规范 S-5.5.5）；不匹配报 E0004
  （反例 `09-default-mismatch.yux`）：

```text
$ yuxc run samples/tutorial/01-intro/09-default-mismatch.yux
ERROR[E0004] 3:39: 类型不匹配（参数 'title' 默认值）: 期望 String，实际 Int
```

## 第 8 章 可空类型

值可能“没有”——用可空类型 `T?` 表达：

```yux
// samples/tutorial/01-intro/12-nullable-intro.yux
fun main() {
    name:String? = "Steve"
    if name != null {
        println name.length
    }
    nothing:String? = null
    println (nothing == null)
}
```

```text
5
true
```

要点（规范 §4.2 / §8.1，ADR-10）：

- `String?` 表示“可能为 null 的字符串”；`null` 字面量表示“没有值”。
- **判空收窄**：`if name != null` 之后，`name.length` 直接可用 ——
  编译器做了**智能转型**，自动把 `name` 当非空处理。
- 直接对可空值调成员会得到**编译提醒 R0001** 并插入运行期空安全守卫；
  `?.` 可安全访问（03-精通 第 9 章）。

## 第 9 章 集合起步

`List` 是变长列表：

```yux
// samples/tutorial/01-intro/08-collections.yux
fun main() {
    xs = List Int()
    xs.add(3); xs.add(1); xs.add(2)
    for v in xs {
        print v
    }
    print xs.size
    print xs.get(0)
}
```

```text
312
3
3
```

要点（规范 §4.3 / §10.2）：

- `List Int()`：**泛型集合**，元素类型 `Int`（泛型语法无尖括号：`List String`）。
- `add` 追加、`get(i)` 读下标、`size` 长度；`for v in xs` 直接迭代。
- 集合变换（`map`/`filter`/`reduce`）见 02-进阶 第 7~8 章。

## 第 10 章 data 类

把若干字段打包成一个值类型：

```yux
// samples/tutorial/01-intro/13-data-class.yux
data User {
    id:Int
    name:String
}
fun main() {
    u = User(1, "Steve")
    println u.toString
    v = User(1, "Steve")
    println (u == v)
}
```

```text
User(id=1, name=Steve)
true
```

要点（规范 §5.3，S-5.3.1）：

- `data 名字 { 属性... }` 自动生成：全参构造器、`equals`、`hashCode`、`toString`、序列化支持。
- `u == v` 按**字段值**比较（值语义）；`toString` 输出 `User(id=1, name=Steve)`。
- 普通类用 `名字 { ... }`（无 `data` 关键字），见 02-进阶 第 3 章。

## 第 11 章 Lambda 起步

函数是一等公民，可以赋值、传参：

```yux
// samples/tutorial/01-intro/14-lambdas-intro.yux
fun main() {
    double:(Int)->Int = x -> x * 2
    println double(5)
    triple:(Int)->Int = { it * 3 }
    println triple(4)
}
```

```text
10
12
```

要点（规范 §4.4 / §7.4，ADR-07）：

- 函数类型写作 `(参数类型)->返回类型`：`(Int)->Int`。
- 箭头 lambda：`x -> x * 2`，`x` 是参数名。
- **块 lambda**：`{ it * 3 }` —— 单参数时可省略参数名，用隐式 `it`。
- 闭包捕获外部变量、高阶函数等深入内容见 02-进阶 第 15~16 章。

## 第 12 章 JVM 互操作初体验

Yux 跑在 JVM 上，Java 类库直接可用：

```yux
// samples/tutorial/01-intro/15-jvm-interop.yux
fun main() {
    m = Math.max(3, 7)
    println m
    s = "  hi  ".trim() as String
    println s
    n = "yux".length
    println n
}
```

```text
7
hi
3
```

要点（规范 §8.5）：

- 静态方法：`Math.max(3, 7)`、`System.currentTimeMillis()`。
- 实例方法：`"  hi  ".trim()`、`"yux".length`。
- **互操作注意**：JVM 方法返回值在 Yux 侧按可空处理，常用 `as String` 收窄为非空
  （`as` 是类型转换，规范 §4.1；规则见 02-进阶 第 13 章）。
- `import java.util.UUID` 等导入语法见 02-进阶 第 18 章。

## 入门速查表

| 语法 | 示例 | 说明 |
| --- | --- | --- |
| 入口 | `fun main() { }` | 程序入口 |
| 输出 | `print x` / `println x` | 不换行 / 换行 |
| 变量 | `x = 1` / `x:Int = 1` | 推断 / 显式类型 |
| 插值 | `"hi $name"` / `"${a + b}"` | `$` 插值 |
| 条件 | `if c { } else { }` | 语句 |
| if 表达式 | `v = if c then a else b` | 作值 |
| 多路分支 | `when x { 1 -> .. else -> .. }` | 语句或表达式 |
| 循环 | `for i in 0..3 { }` / `while c { }` | — |
| 函数 | `fun add(a:Int,b:Int):Int = a + b` | 表达式体 |
| 默认参数 | `fun f(a:Int, b:Int = 1)` | 缺省实参 |
| 可空 | `x:String? = null` | `?` 后缀 |
| 判空 | `if x != null { }` | 智能转型 |
| 集合 | `xs = List Int()` | 泛型无尖括号 |
| data 类 | `data User { id:Int }` | 全自动方法 |
| Lambda | `x -> x*2` / `{ it * 2 }` | 箭头 / 块 |
| 转换 | `x as Int` | 类型转换 |
| JVM | `Math.max(1,2)` | 直接互操作 |
