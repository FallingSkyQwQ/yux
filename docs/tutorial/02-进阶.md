## 第 1 章 函数深入：默认值、递归、表达式体

```yux
// samples/tutorial/02-advance/01-functions-deep.yux
fun scale(x:Int, factor:Int = x * 2):Int = x * factor
fun fib(n:Int):Int {
    if n < 2 { return n }
    return fib(n-1) + fib(n-2)
}
fun main() {
    println scale(3)
    println scale(3, 10)
    println fib(8)
}
```

```text
18
30
21
```

- **默认值引用更早形参**：`factor:Int = x * 2` —— 省略 `factor` 时用实参 `x` 计算。
  编译器在调用点把已提供实参物化为局部，再求默认值（规范 S-5.5.5）。
- **递归**：函数可以调用自身；`fib` 是经典斐波那契。递归组合的更多案例见 03-精通 第 12 章。
- 表达式体 `= x * factor` 与块体 `{ return ... }` 等价。

## 第 2 章 扩展函数

给**已有的类**追加成员方法，无需改源码：

```yux
// samples/tutorial/02-advance/02-extension-functions.yux
Vec2 {
    x:Int
    y:Int
}
fun Vec2.lengthSq():Int {
    return this.x * this.x + this.y * this.y
}
fun Vec2.sum(base:Int = 10):Int {
    return this.x + this.y + base
}
fun main() {
    p = Vec2(3, 4)
    println p.lengthSq()
    println p.sum()
    println p.sum(100)
}
```

```text
25
17
107
```

要点（规范 §5.5，M9）：

- 语法 `fun 接收者类型.方法名(...)`，体内用 `this` 访问接收者。
- 调用时就像普通成员：`p.lengthSq()`。
- 扩展函数也可以有**默认参数**（接收者本身是形参 0）。
- 跨文件扩展：同包顶层扩展函数可被其它文件使用（S-5.5.3）。

## 第 3 章 类、继承与 super

```yux
// samples/tutorial/02-advance/03-classes-inheritance.yux
Animal {
    fun speak() = "generic"
}
Dog extends Animal {
    fun speak() = super.speak() + " dog"
}
fun main() {
    d = Dog()
    println d.speak()
}
```

```text
generic dog
```

要点（规范 §5.1 / §8.7）：

- 类声明 `名字 { 成员 }`；属性 + 方法 + 构造（属性按声明顺序成为构造参数）。
- **继承**：`子类 extends 父类`；子类可覆盖父类方法。
- `super.method()` 调用父类实现（S-8.7.1）；接口继承规则同样适用。
- 访问控制：默认 `public`，可用 `private` / `protected` 修饰（S-5.1.4）。

## 第 4 章 属性访问器

属性默认自动生成 getter/setter；也可以自定义：

```yux
// samples/tutorial/02-advance/04-properties-accessors.yux
Thermostat {
    temperature:Int = 20
    display:Int {
        get { return this.temperature }
        set { this.temperature = 26 }
    }
}
fun main() {
    t = Thermostat(20, 0)
    println t.temperature
    t.display = 99
    println t.temperature
}
```

```text
20
26
```

要点（规范 §5.2，S-5.2.1~5.2.5）：

- `name:Type { get { } set { } }` 自定义读写；只写 `get` 则属性只读（无 setter）。
- 访问器内通过 `this.属性` 访问其它成员（规范中 `value`/`set` 绑定字段，
  v0.1.0-m15 建议用 `this.xxx` 形式，见附录「已知缺陷」）。
- `get` 返回 `Int`、`set` 接收新值；`t.display = 99` 实际写的是 `temperature = 26`。
- 布尔属性自动映射 `isXxx()`（S-5.2.1）。

## 第 5 章 data 类深入：相等与哈希

```yux
// samples/tutorial/02-advance/05-data-classes-deep.yux
data Point {
    x:Int
    y:Int
}
fun main() {
    a = Point(1, 2)
    b = Point(1, 2)
    c = Point(2, 1)
    println (a == b)
    println (a == c)
    println (a.hashCode == b.hashCode)
    println a.toString
}
```

```text
true
false
true
Point(x=1, y=2)
```

要点（S-5.3.1）：

- `equals` 按全部字段比较：`Point(1,2) == Point(1,2)` 为真。
- `hashCode` 与 `equals` 一致：相等的对象哈希必相等（反之不然）。
- `toString` 输出 `Point(x=1, y=2)`。
- 值语义让 data 类特别适合做序列化载体（03-精通 第 5 章）。

## 第 6 章 泛型集合

```yux
// samples/tutorial/02-advance/06-generics.yux
fun main() {
    nums = List Int()
    nums.add(5)
    nums.add(7)
    println nums.get(0)
    println nums.size
    mixed = List Any() as List Any
    mixed.add("str")
    mixed.add(42)
    println mixed.size
}
```

```text
5
2
2
```

要点（规范 §4.3）：

- 泛型**无尖括号**：`List Int`、`List String`、`List Any`。
- `List Int()` 的元素是 `Int`，`get(0)` 直接得到 `Int`。
- 异构集合用 `List Any`；由于构造返回具体实现类型，赋给 `List Any` 需 `as List Any`
  向上转型（互操作可空规则见第 13 章）。

## 第 7 章 集合变换：map / filter

```yux
// samples/tutorial/02-advance/07-collections-map-filter.yux
fun main() {
    xs = List Int()
    xs.add(1); xs.add(2); xs.add(3)
    doubled = xs.map { (it as Int) * 2 }
    println doubled.sum()
    evens = xs.filter { (it as Int) % 2 == 0 }
    println evens.size
}
```

```text
12.0
1
```

要点（规范 §10.2，T-M11-3 注册表）：

- `xs.map { 变换 }`：对每个元素应用 lambda，返回新列表。
- `xs.filter { 条件 }`：保留满足条件的元素。
- 块 lambda 中 `it` 是元素；因集合是 `List Any?`，常配 `(it as Int)` 收窄。
- `sum()` 返回 `Double`（`12.0`）。

## 第 8 章 集合归约：reduce / sort / forEach

```yux
// samples/tutorial/02-advance/08-collections-reduce-sort.yux
fun main() {
    xs = List Int()
    xs.add(3); xs.add(1); xs.add(2)
    total = xs.reduce((a, b -> (a as Int) + (b as Int))) as Int
    println total
    xs.sort((a, b -> (a as Int) < (b as Int)))
    xs.forEach { print (it as Int) }
    println ""
}
```

```text
6
312
```

- `reduce((a, b -> 组合))`：把列表折叠成一个值；`3+1=4, 4+2=6`。
- `sort((a, b -> 比较))`：按比较器排序；`(a < b)` 升序 → `[1,2,3]`。
- `forEach { }`：对每个元素执行副作用（这里是打印）。

## 第 9 章 文本处理：Text 工具类

```yux
// samples/tutorial/02-advance/09-strings-text.yux
fun main() {
    println ("AbC".uppercase() as String)
    println ("AbC".lowercase() as String)
    parts = "a,b,c".split(",")
    println parts.size
    args = List Any() as List Any
    args.add("yux"); args.add(42)
    println (Text.format("%s=%d", args) as String)
}
```

```text
ABC
abc
3
yux=42
```

要点（规范 §10.1）：

- `uppercase` / `lowercase` / `split(sep)` / `trim` 是 String 的**注册表成员**
  （底层 `yux.core.Text` 静态方法）。
- `Text.format("%s=%d", args)`：printf 风格格式化，`%s` 字符串、`%d` 整数。
- JVM 返回值按可空处理 → `as String` 收窄（见第 13 章）。

## 第 10 章 字符串模板进阶

```yux
// samples/tutorial/02-advance/10-string-templates.yux
fun main() {
    name = "Steve"
    level = 3
    println "hi $name"
    println "level=${level + 1}"
    println "\$notInterpolated"
    println "sum=${1 + 2}"
}
```

```text
hi Steve
level=4
$notInterpolated
sum=3
```

要点（规范 §7.6）：

- `$name` 只接标识符；`${...}` 可接任意表达式。
- `\$` 转义；`"line1\nline2"` 支持转义序列（`\n` `\t` 等，规范 §2.5）。

## 第 11 章 when 表达式

```yux
// samples/tutorial/02-advance/11-when-expression.yux
fun pick(n:Int):String = when n {
    1 -> "one"
    2 -> "two"
    else -> "other"
}
fun main() {
    println pick(1)
    println pick(3)
}
```

```text
one
other
```

要点（规范 §6.3，T-M12）：

- when 表达式**产生值**：`when n { 分支 -> 值 }`，可作返回值/实参/变量初始值。
- 非密封 subject 必须 `else` 兜底（E0034）；各分支返回类型会统一（S-6.3.1）。
- 反例：`samples/tutorial/01-intro/16-when-no-else.yux`。

## 第 12 章 密封类型 sealed

```yux
// samples/tutorial/02-advance/12-sealed-types.yux
sealed Shape {
}
Circle extends Shape {
    r:Int
}
Square extends Shape {
    side:Int
}
fun area(s:Shape):Int = when s {
    is Circle -> 3 * s.r * s.r
    is Square -> s.side * s.side
}
fun main() {
    println area(Circle(2))
    println area(Square(3))
}
```

```text
12
9
```

要点（规范 §5.1，T-M12）：

- `sealed` 类：直接子类**必须同文件**（E0036），不可直接实例化（E0035）。
- `is 子类` 分支做**类型收窄**：`s` 收窄为 `Circle` 后可直接访问 `s.r`。
- 覆盖全部子类时 when 表达式**可省 else**（穷尽检查）；漏分支报 E0034。
- 反例：`samples/tutorial/03-master/20-sealed-instantiation.yux`、
  `21-sealed-when-missing.yux`。

## 第 13 章 空安全深入：守卫 / is / as

```yux
// samples/tutorial/02-advance/13-null-safety.yux
fun main() {
    s:String? = "hi"
    println s?.length
    t:String? = null
    println t?.length
    x:Any = 42
    y = x as Int
    println y
    if s != null {
        println (s.uppercase() as String)
    }
}
```

```text
2
0
42
HI
```

要点（规范 §4.2 / §8.1）：

- `?.` 空守卫：接收者为 null 时短路返回 null（`t?.length` 得 `0`——见输出说明：
  这里是守卫后的默认装箱值，实际语义是“安全访问”）。
- `is` 类型检查 + 智能转型（第 12 章、03-精通 第 8 章）。
- `as` 类型转换；对可空 JVM 返回值常用 `x as Int` 收窄。
- **注意**：可空值不能直接传给非空参数（反例 `25-nullable-to-nonnull.yux`，E0004）。
  先判空或用 `as` 收窄。

## 第 14 章 异常：try / catch / finally / throw

```yux
// samples/tutorial/02-advance/14-exceptions.yux
fun risky() {
    throw RuntimeException()
}
fun main() {
    try {
        risky()
    } catch e {
        println "caught"
    } finally {
        println "done"
    }
}
```

```text
caught
done
```

要点（规范 §6.6）：

- `throw 异常` 抛出；`try { } catch e { } finally { }` 捕获与收尾。
- `finally` 无论是否异常都执行（异常链案例见 03-精通 第 16 章）。
- 与 JVM 异常体系互通：`catch e` 可以捕获任何 `Throwable`。

## 第 15 章 闭包

```yux
// samples/tutorial/02-advance/15-lambdas-closures.yux
fun main() {
    x = 5
    addX:(Int)->Int = v -> v + x
    println addX(3)
    mul:(Int)->Int = { it * x }
    println mul(4)
}
```

```text
8
20
```

要点（规范 §7.4，S-7.4.x）：

- lambda 可以**捕获**外层局部变量：`addX` 捕获 `x = 5`。
- 块 lambda `{ it * x }` 同样捕获。
- 捕获发生在 lambda 创建时；跨函数返回 lambda 的“闭包工厂”见 03-精通 第 11 章。

## 第 16 章 高阶函数

```yux
// samples/tutorial/02-advance/16-higher-order-functions.yux
fun applyTwice(f:(Int)->Int, v:Int):Int {
    return f(f(v))
}
fun main() {
    inc:(Int)->Int = x -> x + 1
    println applyTwice(inc, 5)
}
```

```text
7
```

要点：

- 函数可以**作为参数**：`applyTwice` 接收函数 `f` 并调用两次。
- 函数也可以作为返回值（03-精通 第 11 章 `makeAdder`）。
- 结合 `map`/`filter`/`reduce` 就是函数式组合。

## 第 18 章 导入 import

```yux
// samples/tutorial/02-advance/18-imports.yux
import java.util.UUID
fun main() {
    id:UUID? = UUID.randomUUID()

```

要点（规范 §5.7）：

- `import 全限定名` 引入 Java/JVM 类型：`java.util.UUID`。

  `samples/tutorial/04-ecosystem/09-unresolved-import.yux`）。

## 第 21 章 JVM 互操作深入

```yux

    println Math.max(1, 2)
    println Math.min(5, 3)

    println s
    println "hello".length
}
```

```text
true
2
3
abc
5
```

要点（规范 §8.5，S-8.5.x）：

- 静态成员、实例成员、`import`、JavaBean 属性（`p.name` → `getName()`）全部互通。
- 泛型擦除：JVM 侧 `List` 到 Yux 侧元素多为 `Any?`，用 `as` 还原。
