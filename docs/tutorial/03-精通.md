# Yux 精通（第一到第十九章）

> 面向要把 Yux 用于真实项目的读者：并发、序列化、DI、IO、组合技巧。
> 全部示例在 `samples/tutorial/03-master/`，输出与 CI 比对。

---

## 第 1 章 async 协程基础

`async` 是 Yux 的**内置协程**语法（规范 §6.7 / §8.4，T-M14 完整 CPS 状态机）：

```yux
// samples/tutorial/03-master/01-async-basics.yux
async fun doubleAsync(n:Int):Int {
    t = Tasks.launch { }
    await t
    return n * 2
}
async fun compute():Int {
    v = doubleAsync(21)   // async 上下文内挂起调用，直接得声明类型
    return v + 1
}
fun main() {
    print (Tasks.await(compute()) as Int)   // 42 + 1 = 43
    println ""
}
```

```text
43
```

要点：

- `async fun` 声明协程函数；`await 表达式` 挂起直到完成。
- **双 ABI**：async 函数在 async 上下文调用是**挂起调用**（直接得到返回值）；
  在同步上下文调用返回 `Task`，用 `Tasks.await(task)` 阻塞等待。
- 同步侧拿到的结果按可空处理：`Tasks.await(compute()) as Int`。

## 第 2 章 任务 Tasks

```yux
// samples/tutorial/03-master/02-async-tasks.yux
fun main() {
    t = Tasks.launch { print "t1" }
    Tasks.await(t)
    Tasks.sleep(20)
    println "done"
}
```

```text
t1done
```

要点（规范 §10.6）：

- `Tasks.launch { }` 提交一个任务，返回 `Task`（不阻塞）。
- `Tasks.await(task)` 阻塞等待；`Tasks.sleep(ms)` 睡眠。
- `parallel { }` 是语句级并行（第 4 章）。

## 第 3 章 异步异常

协程里抛异常也可以被捕获：

```yux
// samples/tutorial/03-master/03-async-exceptions.yux
async fun risky():Int {
    t = Tasks.launch { throw RuntimeException() }
    await t
    return 1
}
async fun guarded():Int {
    try {
        return risky()
    } catch e {
        return 0
    }
}
fun main() {
    print (Tasks.await(guarded()) as Int)   // catch 捕获 → 0
    println ""
}
```

```text
0
```

要点：

- `Tasks.launch` 内的异常在 `await` 时重新抛出，可用 `try/catch` 捕获。
- CPS 状态机保证挂起点异常也能正确走 catch/finally（T-M14 验收）。

## 第 4 章 parallel 并行块

```yux
// samples/tutorial/03-master/04-parallel.yux
fun main() {
    parallel {
        print "p1"
        print "p2"
    }
    println ""
}
```

```text
p1p2
```

要点（规范 §6.7，S-8.4）：

- `parallel { }` 把块内语句拆成可并行执行的单元，块尾 join。
- 适合**无共享状态**的独立计算；共享可变状态请自行加锁/避免。

## 第 5 章 自动序列化

data 类天然可序列化（规范 §8.3）：

```yux
// samples/tutorial/03-master/05-serialization.yux
import yux.json.Json
data User {
    id:Int
    name:String
}
fun main() {
    u = User(1, "Steve")
    s = Json.serialize(u) as String
    println s
    raw = Json.deserialize(s, User)
    if raw is User {
        println raw.name
    }
}
```

```text
{"id":1,"name":"Steve"}
Steve
```

要点：

- `Json.serialize(对象)` → JSON 文本（data 类按属性生成字段）。
- `Json.deserialize(文本, 类型)` → 还原对象；返回值可空，用 `is` 收窄。
- 泛型/嵌套集合也支持（`yux.json.Json`，S-8.3）。

## 第 6 章 依赖注入 service

```yux
// samples/tutorial/03-master/06-di-services.yux
service Database {
    connect() { }
}
service App {
    fun run(db:Database) {
        db.connect()
        println "run"
    }
}
fun main() {
    db = Database()
    app = App()
    app.run(db)
}
```

```text
run
```

要点（规范 §5.4 / §10.7）：

- `service` 的依赖以方法参数声明（构造器注入的载体）。
- 手动装配：`Database()` / `App()` 直接构造；容器注入见 `yux.di.YuxDi`。
- service 之间的循环依赖会被检测（E0012）。

## 第 7 章 文件 IO

```yux
// samples/tutorial/03-master/07-io-files.yux
import yux.io.IO
fun main() {
    path = "/tmp/yux-tutorial-io.txt"
    IO.writeText(path, "hello yux io")
    println IO.exists(path)
    text = IO.readText(path)
    if text != null {
        println text
    }
}
```

```text
true
hello yux io
```

要点（规范 §10.3）：

- `IO.writeText(path, text)` 写入；`IO.readText(path)` 读取（可空，判空后使用）；
- `IO.exists(path)` 判断存在；`IO.readLines(path)` 按行读取。

## 第 8 章 智能转型组合

```yux
// samples/tutorial/03-master/08-smart-casts.yux
Animal {
    fun speak() = "animal"
}
Dog extends Animal {
    fun speak() = "dog"
}
fun main() {
    pet:Any? = Dog()
    if pet is Dog {
        println pet.speak()
    }
    name:String? = "Steve"
    if name != null {
        println (name.uppercase() as String)
    }
}
```

```text
dog
STEVE
```

要点（规范 §8.1，S-6.1.2 智能转型）：

- `if pet is Dog` 后 `pet` 自动收窄为 `Dog`，直接调 `pet.speak()`。
- `if name != null` 后 `name` 自动去可空。
- 智能转型只对**未被重新赋值**的变量生效（重赋值会得到提醒 R0002）。

## 第 9 章 空守卫惯用法

```yux
// samples/tutorial/03-master/09-null-guards.yux
fun main() {
    s:String? = null
    len = s?.length
    println len
    t:String? = "abc"
    println t?.length
    if s == null {
        println "s is null"
    }
}
```

```text
0
3
s is null
```

要点（规范 §8.1，S-8.1.x）：

- `s?.length`：null 时**短路**返回（Int 守卫落到默认装箱 `0`），非 null 时取真实值。
- `if s == null` / `if s != null` 是显式分支的惯用法。
- 组合使用：`val = a?.b?.c` 链式安全访问。

## 第 10 章 穷尽 when

```yux
// samples/tutorial/03-master/10-when-exhaustive.yux
sealed Shape {
}
Circle extends Shape {
    r:Int
}
Square extends Shape {
    side:Int
}
fun describeExpr(s:Shape):String = when s {
    is Circle -> "circle r=${s.r}"
    is Square -> "square side=${s.side}"
}
fun describeStmt(s:Shape):String {
    when s {
        is Circle -> return "circle r=${s.r}"
        is Square -> return "square side=${s.side}"
    }
}
fun grade(score:Int):String = when {
    score >= 90 -> "A"
    score >= 80 -> "B"
    else -> "C"
}
fun main() {
    println describeExpr(Circle(2))
    println describeStmt(Square(3))
    println grade(95)
    println grade(70)
}
```

```text
circle r=2
square side=3
A
C
```

要点（T-M12）：

- 密封类的 `when` 覆盖全部直接子类时**可省 else**；编译器穷尽检查。
- 新增子类而漏分支 → E0034，让“加需求必改这里”成为编译期约束。
- **无 subject 的 when**（`when { cond -> }`）：条件为布尔表达式（Kotlin 同款）；
  表达式形态必须 `else` 兑底（布尔条件不可证穷尽），语句形态可直落。
- 反例：`samples/tutorial/03-master/21-sealed-when-missing.yux`。

## 第 11 章 函数类型工厂

```yux
// samples/tutorial/03-master/11-function-types.yux
fun applyTwice(f:(Int)->Int, v:Int):Int {
    return f(f(v))
}
fun makeAdder(n:Int):(Int)->Int {
    return x -> x + n
}
fun main() {
    inc:(Int)->Int = x -> x + 1
    println applyTwice(inc, 5)
    add10 = makeAdder(10)
    println add10(1)
}
```

```text
7
11
```

要点：

- 函数返回函数：`makeAdder` 每次调用生成一个新闭包（捕获 `n`）。
- 高阶组合 + 闭包是函数式风格的核心积木。

## 第 12 章 递归组合

```yux
// samples/tutorial/03-master/12-recursion-master.yux
fun fact(n:Int):Int {
    if n <= 1 { return 1 }
    return n * fact(n-1)
}
fun fib(n:Int):Int {
    if n < 2 { return n }
    return fib(n-1) + fib(n-2)
}
fun main() {
    println fact(5)
    println fib(10)
}
```

```text
120
55
```

要点：

- 阶乘 `5! = 120`、斐波那契 `fib(10) = 55`。
- 递归深度受 JVM 栈限制；深层递归考虑改写为循环。

## 第 13 章 格式化输出

```yux
// samples/tutorial/03-master/13-string-formatting.yux
fun main() {
    args = List Any() as List Any
    args.add("Steve")
    args.add(3)
    println (Text.format("name=%s level=%d", args) as String)
}
```

```text
name=Steve level=3
```

要点（规范 §10.1）：

- `Text.format(模板, 实参列表)`：`%s` 字符串、`%d` 整数、`%f` 浮点（Java Formatter 语义）。
- 实参以 `List Any` 传入。

## 第 14 章 异构集合

```yux
// samples/tutorial/03-master/14-collections-any.yux
fun main() {
    mixed = List Any() as List Any
    mixed.add("yux")
    mixed.add(42)
    mixed.add(3.5)
    for v in mixed {
        println v
    }
}
```

```text
yux
42
3.5
```

要点：

- `List Any` 可装任意类型；迭代时元素是 `Any`，需要具体类型时用 `is` 分支/`as`。
- 是 JVM 互操作与 JSON 解析的常见形态。

## 第 16 章 异常链路

```yux
// samples/tutorial/03-master/16-exception-chain.yux
fun inner() {
    throw RuntimeException()
}
fun outer() {
    try {
        inner()
    } finally {
        println "outer finally"
    }
}
fun main() {
    try {
        outer()
    } catch e {
        println "main caught"
    }
}
```

```text
outer finally
main caught
```

要点（规范 §6.6，S-6.6.x）：

- 异常沿调用链上抛：`inner → outer → main`。
- `finally` 在**每一层**都执行；catch 在最近的匹配层接住。
- try/finally 组合可以做资源清理。

## 第 17 章 扩展方法组合

```yux
// samples/tutorial/03-master/17-extension-methods-deep.yux
Vec2 {
    x:Int
    y:Int
}
fun Vec2.norm():Int = this.x * this.x + this.y * this.y
fun Vec2.distance(other:Vec2, scale:Int = 1):Int {
    dx = this.x - other.x
    dy = this.y - other.y
    return (dx * dx + dy * dy) * scale
}
fun main() {
    a = Vec2(3, 4)
    b = Vec2(0, 0)
    println a.norm()
    println a.distance(b)
    println a.distance(b, 2)
}
```

```text
25
25
50
```

要点：

- 扩展函数 + 默认参数 + 表达式体组合出简洁的领域 API。
- 这是给“别人的类型”加行为的主要手段（类似 Kotlin 扩展）。

## 第 18 章 顶层属性访问器

```yux
// samples/tutorial/03-master/18-top-level-accessors.yux
serverName:String {
    get { return "lobby-1" }
}
maxPlayers:Int = 100 {
    get { return value + 10 }
}
fun main() {
    println serverName
    println maxPlayers
}
```

```text
lobby-1
110
```

要点（规范 §5.6，S-5.2 同规则）：

- 顶层属性也可带自定义访问器；只写 `get` 即为只读。
- **init + 访问器可组合**：`x:Int = 10 { get { } }` 先按初始化器写入 backing field，
  访问器内 `value` 读该字段（`maxPlayers` 读得 100 后 +10）。
- 常被用作配置文件/常量表。

## 第 19 章 综合并发

```yux
// samples/tutorial/03-master/19-async-combined.yux
async fun doubleAsync(n:Int):Int {
    return n * 2
}
fun main() {
    async {
        v = doubleAsync(4)
        println v
    }
    parallel {
        print "a"
        print "b"
    }
    Tasks.sleep(10)
    println ""
}
```

```text
8
ab
```

要点：

- `async { }` 块内是 async 上下文：挂起调用直接取返回值。
- `parallel`、`Tasks` 与 `async` 可组合；并发模型见规范 §8.4。
