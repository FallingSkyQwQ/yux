## 第 1 章 标准库地图

Yux 标准库以 JVM 包形式存在，命名前缀 `yux.*`：

| 包 | 内容 | 示例 |
| --- | --- | --- |
| `yux.core` | `print`/`println` 宿主、`Text`（大小写/split/format） | `01-stdlib-core.yux` |
| `yux.collection` | `List`/`Map`/`Set` 注册表成员（map/filter/reduce/sort/sum/max/first/forEach） | `02-stdlib-collections.yux` |
| `yux.json` | `Json.serialize` / `Json.deserialize` | `03-stdlib-json.yux` |
| `yux.io` | `IO.readText/writeText/readLines/exists` | `04-stdlib-io.yux` |
| `yux.async` | `Task` / `Tasks.launch/await/sleep/parallel` | `05-stdlib-async.yux` |
| `yux.di` | `service` 注入、`YuxDi` 容器 | `06-stdlib-di.yux` |
| `yux.net` | `Http.get(url)`（HTTP GET） | 按需查阅 |
| `yux.serializer` | 序列化 SPI | `yux.json` 的底层 |

标准库特性（T-M11-3 **注册表**）：

- `xs.map { }`、`"AbC".uppercase()` 这类“成员方法”在语言层面注册
  （`JvmExtensions`），底层降级为 `yux.collection.Colls` / `yux.core.Text` 静态调用。
- 完整清单见规范 §10 与 `yux-stdlib/` 源码。

```yux
// samples/tutorial/04-ecosystem/01-stdlib-core.yux
fun main() {
    print "no newline"
    println ""
    println "yux core"
    println ("Hello".uppercase() as String)
    args = List Any() as List Any
    args.add("eco")
    println (Text.format("==%s==", args) as String)
}
```

```text
no newline
yux core
HELLO
==eco==
```

## 第 2 章 工具链

### 安装

```bash
# 一键安装（Linux/macOS/WSL，JDK 21+）
curl -fsSL https://raw.githubusercontent.com/FallingSkyQwQ/yux/main/setupyux.sh | bash

# 锁定版本
curl -fsSL https://raw.githubusercontent.com/FallingSkyQwQ/yux/main/setupyux.sh | bash -s -- --ref v0.1.0-m15
```

脚本细节：优先下载 Releases 免编译产物，否则源码编译；安装到 `~/.yux/bin`；
幂等；`--help` 查看全部选项。

### 命令一览

| 命令 | 作用 |
| --- | --- |
| `yuxc run <file>` | 编译并运行（输出 stdout；编译失败输出诊断并退出 1） |
| `yuxc check <file>` | 只做语义检查（输出类型信息） |
| `yuxc lex <file>` | 词法 token |
| `yuxc ast <file>` | 语法树 |
| `yuxc ir <file>` | 中间表示 |
| `yuxc build` | 按 `build.yml` 构建工程（生成 Gradle 脚本） |
| `yuxc test` | 运行工程测试 |
| `yuxc --plugin <jar>` | 加载编译器插件 |

诊断格式：`ERROR[E0004] 行:列: 消息`；正例零错误，反例退出码 1。

## 第 3 章 集合库实战

```yux
// samples/tutorial/04-ecosystem/02-stdlib-collections.yux
fun main() {
    xs = List Int()
    xs.add(5); xs.add(2); xs.add(8)
    println xs.sum()
    println (xs.max() as Int)
    println (xs.first() as Int)
    ys = xs.map { (it as Int) * 2 }
    println ys.sum()
    evens = xs.filter { (it as Int) % 2 == 0 }
    println evens.size
    total = xs.reduce((a, b -> (a as Int) + (b as Int))) as Int
    println total
    xs.sort((a, b -> (a as Int) > (b as Int)))
    xs.forEach { print (it as Int) }
    println ""
}
```

```text
15
8
5
30.0
2
15
528
```

要点：

- `xs.sum()` 按元素类型收窄：`List Int` → `Int`（`15`）；`map` 结果（`List Any`）仍返回 `Double`（`30.0`）；`max`/`first` 可空（`as Int` 收窄）；`reduce` 折叠；
- `sort(降序比较器)` → `[8,5,2]` → forEach 打印 `528`。

## 第 4 章 JSON 与 IO 实战

```yux
// samples/tutorial/04-ecosystem/03-stdlib-json.yux
import yux.json.Json
data Item {
    id:Int
    tag:String
}
fun main() {
    it = Item(7, "sword")
    s = Json.serialize(it) as String
    println s
    raw = Json.deserialize(s, Item)
    if raw is Item {
        println raw.tag
    }
}
```

```text
{"id":7,"tag":"sword"}
sword
```

```yux
// samples/tutorial/04-ecosystem/04-stdlib-io.yux
import yux.io.IO
fun main() {
    path = "/tmp/yux-eco-io.txt"
    IO.writeText(path, "line1")
    lines = IO.readLines(path)
    println lines.size
    println IO.exists(path)
}
```

```text
1
true
```

要点：序列化/反序列化往返；`IO.readLines` 按行读。反序列化结果可空 → `is` 收窄。

## 第 6 章 工程化：从单文件到项目

- **单文件脚本**：`yuxc run xxx.yux` 即可（本教程全部示例都是这个形态）。
- **项目工程**：根目录放 `build.yml`，`yuxc build` 生成 Gradle 脚本并构建

- **多文件**：一个文件对应一组顶层声明；跨文件用 `import`（S-5.7）。
- **混合项目**：Yux 与 Java/Kotlin 共存，见 `docs/05-混合项目示例.md`。

## 第 7 章 Minecraft 插件门户

Yux 的第一场景是 Minecraft（Paper/Bukkit）插件，能力通过**编译器插件**注入
（ADR-11，非语言内建）：

```yux
// samples/minecraft-hello/src/main.yux（M8 示例）
import org.bukkit.event.player.PlayerJoinEvent
plugin MyServer {
    description = "YuxPlugin SDK 示例"
    onEnable { print "MyServer 已启用" }
}
event PlayerJoin(player) {
    player.sendMessage "欢迎 ${player.name} 加入服务器"
}
command "/hello" {
    permission = "myserver.hello"
    execute(sender, args) {
        sender.sendMessage "Hello from YuxPlugin!"
    }
}
config ServerConfig {
    motd = "Welcome to MyServer"
    maxPlayers = 100
}
permission "myserver.admin" {
    description = "管理员权限"
    default = OP
}
task repeat(interval:20) {
    print "tick"
}
```

要点：

- `plugin`/`event`/`command`/`config`/`permission`/`task` 都是插件关键字；
- 完整 SDK 设计见 `docs/03-YuxPlugin-SDK-设计.md`；
- 本教程是**纯语言 + 生态门户**，Minecraft 细节请以 SDK 文档为准。

## 第 8 章 注册表成员与互操作模式

```yux
// samples/tutorial/04-ecosystem/08-registry-members.yux
fun main() {
    println "hello".length
    parts = "a,b,c".split(",")
    println parts.size
    xs = List Int()
    xs.add(1); xs.add(2)
    tripled = xs.map { (it as Int) * 3 }
    n = tripled.first() as Int
    println n
}
```

```text
5
3
3
```

要点：

- 注册表成员：`"hello".length`、`"a,b,c".split(",")`、`xs.map { }`、`first()`；
- 块 lambda 实参后可直接继续链式调用：`xs.map { }.first()`（S-7.2 无括号调用，缺陷已修复）。

| 概念 | Yux | Kotlin | Java | Python |

| when 语句 + is 分支内 `return`（密封 subject，无 else）导致 JVM VerifyError | 后端补发与返回类型匹配的兜底返回，尾部 Label 不再悬空 | `StmtEmitterBugfixTest` | `03-master/10-when-exhaustive.yux`（语句形态） |

| 无 subject 的 when（`when { cond -> }`） | 解析器：`when` 后直接 `{` 时 subject 置空；sema：条件须 `Boolean`、`is` 分支非法、表达式形态必须 `else`；IRGen：条件直接分支 | `StmtEmitterBugfixTest` + `TypeCheckerTest` + `PrattParserTest` | `03-master/10-when-exhaustive.yux` |
| 顶层属性 `init + 访问器` 组合（`x:Int = 10 { get {} }`） | 初始化表达式解析在访问器块前停下（`{ get`/`{ set` 前瞻不再当作块 lambda 实参） | `StmtEmitterBugfixTest` + `PrattParserTest` | `03-master/18-top-level-accessors.yux` |

## 常见问题 FAQ

**Q1：`print` 和 `println` 区别？**
`print` 不换行；`println` 末尾换行。本书正例大多用 `println` 便于逐行对照。

**Q2：为什么 JVM 方法返回值要 `as String` / `as Int`？**
JVM 互操作返回值按**可空**处理（S-8.5）。`as` 收窄为非空后即可直接使用。

**Q3：`List Any()` 为什么要 `as List Any`？**
构造返回具体实现类型（`ArrayList`），赋给接口类型 `List Any` 需要一次显式向上转型。

**Q4：何时该用 `when` 而不是 `if/else`？**
三分支以上、或要做穷尽检查（密封类型）时用 `when`；两分支简单判断用 `if`。

**Q5：教程示例与最新 main 不一致怎么办？**
教程锁定 `v0.1.0-m15`。示例快照由 CI 与编译器逐字节比对；若 main 有语言变更导致
快照过期，CI 会先红，PR 会附带快照更新。
