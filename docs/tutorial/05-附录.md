## §1 语法速查

### 声明

```text
Program       ::= { ImportDecl | TopLevelDecl }
ImportDecl    ::= 'import' QualifiedName
ClassDecl     ::= [ 'data' | 'service' | 'sealed' ] Identifier [ 'extends' Type ]
                  [ 'implements' Type { ',' Type } ] '{' { Member } '}'
Member        ::= PropertyDecl | FunctionDecl
PropertyDecl  ::= Identifier ':' Type [ '=' Expr ] [ '{' Accessor { Accessor } '}' ]
FunctionDecl  ::= [ 'async' ] 'fun' [ ReceiverType '.' ] Identifier '(' Params ')'
                  [ ':' Type ] ( '=' Expr | Block )
TopLevelDecl  ::= ClassDecl | FunctionDecl | PropertyDecl
```

### 语句

```text
Stmt          ::= VarDecl | Assign | ExprStmt | If | When | For | While
                | Return | Break | Continue | Try | AsyncBlock | ParallelBlock | UnsafeBlock
VarDecl       ::= Identifier [ ':' Type ] '=' Expr
Assign        ::= LValue ( '=' | '+=' | '-=' | '*=' | '/=' | '%=' ) Expr
If            ::= 'if' Expr Block [ 'else' ( If | Block ) ]
When          ::= 'when' Expr '{' { ( Expr | 'is' Type | 'else' ) '->' Stmt } '}'
For           ::= 'for' Identifier 'in' Expr Block
While         ::= 'while' Expr Block
Try           ::= 'try' Block { 'catch' Identifier Block } [ 'finally' Block ]
AsyncBlock    ::= 'async' Block | 'parallel' Block | 'unsafe' Block
```

### 表达式

```text
Expr          ::= Literal | Identifier | StringTemplate | List
                | IfExpr | WhenExpr | Lambda | Call | MemberAccess | IndexAccess
                | Unary | Binary | Cast | NullCheck | New
IfExpr        ::= 'if' Expr 'then' Expr 'else' Expr
WhenExpr      ::= 'when' Expr '{' { Expr '->' Expr } 'else' '->' Expr '}'
Lambda        ::= Identifier '->' Expr | '{' [ Identifier ] '->' Expr '}'
Cast          ::= Expr 'as' Type
NullCheck     ::= Expr '?.'
Call          ::= ( 'fun' )? Expr '(' Args ')'
```

> 完整 EBNF 见 `docs/01-Yux-语法规范.md` §3 / §7.1。

## §7 术语表

| 术语 | 定义 |
| --- | --- |
| golden 示例 | 附 `.stdout`/`.err` 快照、由 CI 逐字节验证的示例 |
| 正例 / 反例 | 应成功运行（比对 stdout）/ 应编译失败（比对 stderr + 退出码） |
| 注册表成员 | 通过 `JvmExtensions` 注册、底层降级为静态调用的语言级成员方法 |
| 双 ABI | async 函数在 async 上下文为挂起调用、同步上下文返回 `Task` 的双形态 |
| 智能转型 | 判空/`is` 后编译器自动收窄变量类型 |
| 空守卫 | 可空接收者调用时插入的运行期判空（R0001 提醒） |
| 穷尽检查 | 密封类型 `when` 必须覆盖全部直接子类的编译期检查（E0034） |
| 物化实参 | 默认参数补齐时把已提供实参先存为局部（S-5.5.5） |
